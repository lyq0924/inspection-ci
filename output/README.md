# 巡检报告输出目录

此目录用于存放巡检报告。

## 目录结构

```
output/
├── latest/          ← 最新一次巡检报告
├── archive/         ← 历史巡检报告（按日期归档）
└── README.md        ← 本文件
```

## 报告格式

每次巡检会生成以下格式的报告：

| 格式 | 文件名 | 说明 |
|------|--------|------|
| Excel | `巡检结果-*.xlsx` | 详细结果表格，可筛选排序 |
| HTML | `巡检报告-*.html` | 可视化报告，浏览器打开 |
| Markdown | `巡检报告-*.md` | 文本报告，便于版本对比 |

## CI/CD 中的行为

- 本地运行：报告输出到 `output/latest/`
- CI 运行：报告上传到 GitHub Artifacts，可下载后放入此目录
